# Working with Sammy (founder notes)

Living notes on how Sammy works, so any future session starts aligned. Update as we learn.

- Runs Maji Safi (main company). Ug Life is a **side project**: keep it separate and confirm at
  the start of each conversation which one a task is about.
- Not a game developer. Wants expert judgement and clear recommendations, and is happy to have
  earlier drafts overruled when the reason is stated.
- Thinks in systems: wants the thing to run itself (agents, support, growth), "like Google building
  a game in-house where everyone is part of it", not just a build.
- Inspired by Lagos Life going viral. Cares about virality and about it looking good.
- Constraints (2026-10-24): ~2 h/week, $0/month unless absolutely needed, sole human on call,
  web link (PWA) first.
- Prefers being asked focused questions before big plans; agrees quickly when the reasoning is clear.
- Based in Kampala; can photograph real streets for reference (an edge to use).
- Doesn't want manual setup steps (keys, dashboards, settings). Expects Claude to find a way and
  finish end to end with the accounts already connected, then report. Ask only for real decisions.
- Approves broad requests up front ("do all, I'll approve"); merging to make things live is OK
  when he asks for it to be live.
- Live Ug Life: https://ug-life.netlify.app (Netlify team sammygedamua, site ug-life). Control Room
  password is the ADMIN_TOKEN env var on that Netlify site.
- Gives feedback by playing it ("ok now it sort of works") and asking for more, in bursts.
  Wants local, recognisable Kampala life: bodas, rolex, landmarks, a dense street.
- "No demo": any feature that looks like it pays or saves must really pay and save, checked by
  the server, with no way to claim twice. Prefers fewer real features to many fake ones.
- Wants others to be able to add content easily (see `game/CONTENT.md`).
- Asks "does it work, can I share it, is it saved": answer those plainly at the end of each round.
- Thinks in "Kampala texture": Luganda greetings, boda culture, rolex, real neighbourhoods,
  hot areas, landlords and rent. Wants the game to feel like the city and sound like it.
- Wants real-money style economies (tokens pegged to UGX, betting-like games). Claude keeps the
  game money closed (no cash-in/out, no betting) because that needs gambling and e-money licences;
  explain the licensed path when it comes up rather than building it unasked.
- Wants clear "levers": places to update the game whenever he likes (Control Room → Grow), and
  ways for players to add to it (ideas, votes, billboards, land). Values: everything works, no
  mock-ups; mobile first; easy to share; grows through events and real brands.
- Explain money boundaries plainly: real money in (top-ups) is fine once the business is set up;
  real money out or betting is not.
- Benchmarks against Lagos Life feature by feature (needs, homes, travel, dating, elections,
  billboards, Nepo/Lapo start). When he says "see what people say you can do", research the
  inspiration and bring parity in Kampala texture, then add ideas of our own.
- Wants places that feel big: universities (Makerere), markets (Owino), nightlife (Kabalagala),
  moving between them like real Kampala. Wants to "talk to girls and people": keep it friendly
  and 18+, never explicit, with report and block everywhere.
- Wants control over the experience (e.g. mute sounds): give settings, not one-size defaults.
- Wants his projects organised on GitHub (Ug Life in its own repo, beside his other projects).
  Repo creation needs him once: the GitHub app can't create repos for him.
