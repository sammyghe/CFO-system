Safi Treatment Technical Data Sheet SF-TDS-001 · Maji Safi · Belize spring · 3

This is what Safi Treatment can do. Ten standard modules, and the raw-water test decides which ones we fit. For a spring we expect the solid blue set: micron filters, ultrafiltration, UV, cleaning and the controller. Iron media or carbon only if the test shows iron or taste problems. Reverse osmosis only for salty water, and then the product is sold as purified, not spring. The full data sheet goes with this deck.
